## O projeto em uma linha

**Top Filme:** app gratuito que recomenda filme pelo estado emocional do usuário (B2C). Os dados gerados são o ativo, vendido como inteligência psicográfica para produtoras, agências e streaming (B2B). O protótipo atual é só frontend: não grava nada.
