## Objetivo

Mostrar a análise financeira do projeto e convencer investidores a apostarem na proposta — com números.

O enunciado manda revisitar o Canvas tendo em mente sete pontos de atenção:

1. **Identificar quem é o "pagador" e quem é o usuário**
2. Ter claro para quem e como se gera valor
3. Definir como monetizar o projeto
4. Definir qual é o "core" do negócio
5. Identificar as atividades que roubam a escala financeira
6. Buscar parceiros
7. Evoluir o projeto/serviço para aumentar as receitas

O ponto 1 é a tese central do Top Filme: o usuário do app não é quem paga. A atividade pede exatamente que essa inversão apareça em números.
